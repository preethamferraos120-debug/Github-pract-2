# SkyFetch Weather Dashboard (Part 2)

This project adds user interaction features to a weather dashboard:

- Search weather by city name
- API calls refactored with `async/await`
- Graceful error handling with `try/catch`
- Validation for empty input and unknown cities
- Loading state while weather data is being fetched

## Run locally

Open `index.html` in a browser.

## Demo checklist

- Search a valid city (e.g., London)
- Search an invalid city (e.g., xxxxx)
- Try empty input
- Observe loading state on each search
